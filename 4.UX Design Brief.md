18. UX Rules

The development team and AI must follow these rules:

Sand #F0EDE4 is the default application background.
Do not use pure white as the global background.
Use warm-white cards to establish hierarchy.
Use Deep Teal as the main brand/action color.
Every important action must provide loading, success, and error feedback.
Candidate evidence should be reachable within minimal navigation depth.
Do not hide important verification information behind only a numeric score.
Integrity results must show evidence rather than unsupported accusations.
Game XP must remain visually separate from professional capability.
Monitoring features require clear consent states.
All screens must support keyboard navigation.
Maintain accessible text/background contrast.
Use consistent spacing, typography, cards, buttons, and status indicators.
Avoid unnecessary animations.
Game mode may use richer animation and visual effects without changing the core dashboard design system.
