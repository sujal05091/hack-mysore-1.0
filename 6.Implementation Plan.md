# Implementation Plan
VerifiCode — Verifiable Proof-of-Work Engineering Discovery & Hiring Platform

## PHASE 1: Project Foundation (Current Priority)
**Owner:** ME (Main Developer)
- Initialize Git monorepo structure.
- Scaffold Next.js frontend (TypeScript, Tailwind CSS, shadcn/ui).
- Scaffold FastAPI backend (Python, SQLAlchemy, Alembic).
- Establish design system tokens (Sand background, Inter font).
- Configure root-level `.gitignore`, linting, and formatting.

## PHASE 2: Authentication & Database Schema
**Owner:** ME (Main Developer)
- Integrate Supabase Auth (Candidate, Reviewer, Recruiter roles).
- Define base database schema with SQLAlchemy & Alembic (Users, Profiles).
- Setup Route guards and RBAC (Role-Based Access Control) in Next.js.

## PHASE 3: Base Dashboards & UI
**Owner:** ME (Main Developer)
- Build Candidate Dashboard layout.
- Build Reviewer Dashboard layout.
- Build Recruiter Dashboard layout.
- Create shared components (Buttons, Cards, Modals, Forms).

## PHASE 4: Project Management & GitHub Verification
**Owner:** ME (Main Developer) & Friend 1 (GitHub)
- **ME:** Build forms for Candidates to submit projects (URL, description, stack, deployments, ADRs).
- **Friend 1:** Implement GitHub integration (parsing repositories, commits, generating code evidence).

## PHASE 5: Verified Coding Arena (My Core Feature)
**Owner:** ME (Main Developer)
- Integrate Monaco Editor into a focused challenge UI.
- Build the challenge selection and rules flow.
- Develop Docker Sandbox architecture for secure code execution.
- Implement test-case running and code submission pipeline.
- Wire up frontend to display real-time terminal output and results.

## PHASE 6: AI Company & Opportunity Finder
**Owner:** Friend 2 (Company Finder)
- Implement search by skills, experience, and expected package.
- Integrate Hunter.io to find and shortlist top 10 relevant companies.
- Scrape official websites for skills/tech and problem statements.
- Build interactive gaming/futuristic frontend for results (Company, Website, LinkedIn, Email, Skills, Problem).
- Build Voice UI (Text-to-Speech question, Speech-to-Text answer).
- Implement AI answer evaluation and dynamic follow-up questioning.

## PHASE 7: Decision Fusion & Integrity Engine
**Owner:** Friend 3 (Decision Fusion)
- Capture Coding Arena telemetry (typing, pastes, tab switches).
- Build the Integrity Engine to aggregate telemetry into an Integrity Report (Normal, Review Required, Disqualified).
- Build Capability Scoring Engine (aggregate GitHub evidence, Coding Arena scores, AI Defense scores, and Human Reviews).
- Construct the final verified Candidate Profile and Ranking Engine.

## PHASE 8: Recruitment & Reviewer Flows
**Owner:** ME (Main Developer)
- Build Recruiter search/filter system.
- Build Shortlist and Outreach views.
- Build Reviewer rubric UI and feedback forms.

## PHASE 9: Integration & QA
**Owner:** Entire Team
- Integrate all branch features into the `develop` branch.
- End-to-end testing of the complete flow: *Build → Document → Defend → Verify → Discover.*
- Finalize styling and UX transitions.

## PHASE 10: Engineering Game
**Owner:** ME (Postponed to Last)
- Implement Three.js/React Three Fiber 3D environment.
- Gamify knowledge, coding, debugging, and system design challenges.
- Implement boss battles and XP tracking (kept strictly separate from professional capability scores).
