Backend Schema — Database & Data Structure

Backend Schema defines how VerifiCode stores, connects, validates, and retrieves all application data.

The database will use PostgreSQL through Supabase, with UUID primary keys, timestamps, foreign-key relationships, and role-based access control.

1. Core User Schema
users

Stores the common identity of every platform user.

Field	Type	Description
id	UUID	Primary key
email	VARCHAR	User email
full_name	VARCHAR	User name
role	ENUM	Candidate / Reviewer / Recruiter / Admin
avatar_url	TEXT	Profile image
created_at	TIMESTAMP	Account creation
updated_at	TIMESTAMP	Last update

 ├── reviewer_profiles

Backend Schema Principle

Every important capability claim in VerifiCode must be traceable back to an evidence source — project, coding challenge, technical review, or project defense.
