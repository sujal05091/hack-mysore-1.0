App Flow — Navigation Logic

App Flow defines how users move through VerifiCode — from login to project verification, coding challenges, AI defense, capability profile, game, and recruiter discovery.

The navigation must be role-based, so Candidates, Reviewers, and Recruiters see different dashboards and workflows.
